# Microgreen Guide · Grow Lab

[Open all five tools](https://samueldovgin.github.io/microgreen-grow-lab/)

Coco coir, seed & water, lighting, rack clearance and a browser-local grow log, with rendered research guides and source references.

GitHub Pages publishes this repository from `main` / root. This repository contains only the portable website. The full research archive is maintained separately.

Saved plans and grow-log records stay in each browser. Use grow-log export/import to transfer records between devices.
