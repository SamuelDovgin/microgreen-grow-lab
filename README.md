# Microgreen Guide · Grow Lab

[Open tools and tray-care guide](https://samueldovgin.github.io/microgreen-grow-lab/)

Coco coir, MaxiGro mixing, seed & water, lighting, rack clearance and a browser-local grow log, with tray sanitation steps, rendered research guides and source references.

This is a generated website mirror. Edit the source archive instead. After a source change on main, GitHub Actions rebuilds the research pages, checks links and calculators, then syncs this repository. GitHub Pages publishes main / root. The full research archive is maintained separately.

`deployment.json` records the source revision and SHA-256 hashes of the website files.

Saved plans and grow-log records stay in each browser. Use grow-log export/import to transfer records between devices.
