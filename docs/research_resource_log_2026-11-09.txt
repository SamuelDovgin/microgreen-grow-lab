DECISION
Cards show a deliberately broad grower envelope: sunflower 3–4 / 0–3 / 3–7 days; radish 2–4 / 0–2 / 3–5; broccoli 2–3 / 0–2 / 3–7; peas 2–5 / 0–3 / 4–8; mung 3–4 / 0 / 3–7. Order is covered germination / additional blackout / light. These are not exhaustive source extrema. Earlier/later harvest targets and alternate methods explain outliers.
Broccoli card now distinguishes optional one-to-two-inch stretch from earlier light; radish likewise distinguishes an optional stretch. No extra blackout is added to mung’s existing covered establishment.
